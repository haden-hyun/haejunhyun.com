Github와 Cloudflare 연동

Github 설정

Github의 Quartz 페이지를 방문하여 해당 템플릿을 나만의 repository에 복사하여 새로운 저장소를 생성한다.

‘Use this template’ → ‘Create a new repository’
‘Repository Name’ 입력 → ‘Public’ 설정 → ‘Create Repository’

Cloudflare 설정

‘빌드’ → ‘Workers 및 Pages’ 탭 → ‘응용 프로그램 생성’
‘Pages’ 탭 → ‘기존 Git 리포지토리 가져오기’
‘Github’ 탭 → 위에서 생성한 리포지토리 선택

빌드 설정:

  • 프로젝트 이름: 사이트명
  • 프로덕션 분기: v4
  • 빌드 명령: npx quartz build
  • 빌드 출력 디렉터리: public

Obsidian에서 노트 게시

Flowershow 플러그인을 사용하면 Obsidian 노트를 Github 저장소에 업로드 한다.

Github 접근 토큰 발급: 여기에서 토큰 생성 (Tokens (classic) 탭)

설정: Note(token 이름) → Expiration: No expiration → repo 전체 선택

토큰은 1회만 확인 가능 — 반드시 별도 저장할 것!
