DROP 테이블 제거

Created 2024-11-12Revised 2026-07-02Updated 2026-10-241 min read #postgresql

요약

  • DROP: 대상 전체를 삭제 — 절대 되돌릴 수 없음
  • DELETE: 원하는 데이터만 삭제, 되돌릴 수 있음
  • TRUNCATE: 인덱스 및 데이터 삭제, 테이블은 유지되지만 되돌릴 수 없음
