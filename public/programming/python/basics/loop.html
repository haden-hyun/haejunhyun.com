for, while과 Pythonic 순회

for, while과 Pythonic 순회

Aug 25, 20265 min read

  • programming/python

Summary

  • for는 정해진 데이터 묶음을 순회할 때, while은 종료 시점을 모르는 조건 반복에 쓴다
  • enumerate는 인덱스와 값을 동시에, zip은 여러 리스트를 병렬로 순회한다
  • 딕셔너리는 items()로 키와 값을 동시에 꺼낸다

들어가며

코딩으로 자동화를 구현할 때 핵심이 되는 기능이 반복문(loop)이다. 이 글에서는 Python의 대표적인 반복문 for와 while의 차이, 그리고 반복문을 더 Pythonic하게 만드는 enumerate, zip 등을 정리한다.

for와 while

반복문은 크게 “횟수가 정해진 경우”와 “조건이 만족될 때까지”로 나뉜다.

for 문

for는 리스트·튜플·문자열 등 정해진 데이터 묶음(Iterable)을 처음부터 끝까지 하나씩 꺼내 처리할 때 쓴다. 반복 횟수가 데이터 길이만큼 명확하게 정해진다.

while 문

while은 반복 횟수를 미리 알 수 없을 때, 특정 조건이 참인 동안 계속 반복한다. 조건이 영원히 참이면 무한 루프에 빠질 수 있어 내부에 종료 조건(break)을 반드시 고려한다.

Pythonic한 순회 방법

range()

range()는 숫자 범위를 생성한다. 단순히 횟수만큼 반복하거나 인덱스 숫자가 필요할 때 쓴다.

enumerate()

enumerate()는 인덱스와 값을 동시에 돌려준다. 리스트를 돌면서 몇 번째인지도 알아야 할 때 쓴다. range(len(list)) 대신 enumerate를 쓰는 것이 Pythonic한 방식이다.

zip()

zip()은 여러 리스트를 병렬로 순회한다. 두 개 이상의 리스트를 동시에 처리할 때 쓴다. 길이가 짧은 리스트를 기준으로 종료된다.

딕셔너리 순회

딕셔너리를 for에 넣으면 기본적으로 키만 나온다. 값은 values(), 키와 값을 동시에는 items()로 꺼낸다.
