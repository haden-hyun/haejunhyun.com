요일과 기간, 월 경계 날짜 유틸

요일과 기간, 월 경계 날짜 유틸

Created 2024-02-20Revised 2026-07-062 min read #pandas

Summary

  • while 루프에 timedelta/relativedelta를 더해 기간별 날짜 문자열 리스트를 만든다
  • dt.day_name()은 요일 문자열을, dt.dayofweek는 요일 정수(월=0)를 반환한다
  • 요일 정수를 5로 나눈 몫으로 평일·주말을 구분한다

기간별 날짜 문자열 생성

시작일부터 끝일까지 일별 또는 월별로 YYYYMMDD(또는 YYYYMM) 문자열 리스트를 생성한다. 일별은 timedelta(days=1), 월별은 relativedelta(months=1)을 더한다.

요일 추출

요일 문자열

dt.day_name()은 Monday, Sunday 같은 요일 이름을 반환한다.

요일 정수

dt.dayofweek(또는 dt.weekday)는 월요일을 0, 일요일을 6으로 반환한다.

평일 / 주말 구분

요일 정수를 5로 나눈 몫이 1이면 주말(토=5, 일=6)이다.

월 시작일·끝일 구하기

날짜를 입력받아 그 달의 첫날과 끝날을 구한다. 끝날은 다음 달 1일에서 하루를 뺀다.
