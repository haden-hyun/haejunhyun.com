Git과 GitHub

Summary

  • Git은 변경된 내용만 관리하는 비전 관리 도구이며, GitHub는 Git으로 관리한 코드를 저장하는 공간이다.
  • Repository·Branch·Commit·Origin·Clone 등 기본 용어를 이해해야 Git 명령어를 올바르게 사용할 수 있다.
  • git init → git remote add → git add/commit → git push 순서로 로컬 코드를 원격 저장소에 업로드한다.

Git과 GitHub

Git

Git은 변경된 내용만 관리하는 비전 관리 도구다. 코드를 언제 누가 어디를 변경했는지 확인할 수 있으며, 코드를 합치거나 이전 버전으로 돌아갈 수 있다.

GitHub

GitHub는 Git으로 관리한 코드를 저장하는 공간이다. Git으로 관리한 코드는 push를 통해 GitHub에 업로드한다.

  • Git: 코드 관리
  • GitHub: 코드 저장

용어 정리

Repository

Repository는 특정 프로젝트의 저장소를 의미한다.

  • Local Repository: 개인 컴퓨터에 저장된 로컬버전의 프로젝트 저장소
  • Remote Repository: 원격 서버에 저장되는 프로젝트 저장소로 여러 명과 공유하기 위한 저장소

Branch

Branch는 Repository 안에서 독립적으로 어떤 작업을 하기 위한 공간이다.

  • default Branch: 중심이 되는 Branch
  • remote Branch: 원격 저장소(Remote Repository)에 있는 Branch

Commit / Origin / Clone

  • Commit: 업로드 시 업데이트한 내용을 기입
  • Origin(원격 저장소): origin은 원격 저장소의 이름이다. 예) origin/hyunae는 원격 저장소 안의 hyunae 브랜치를 뜻한다.
  • HEAD: 현재 나의 작업공간을 의미한다. 예) origin/HEAD는 원격 저장소 안의 현재 코드 상태를 뜻한다.
  • Clone: 원격 저장소(Remote Repository)로부터 소스코드를 로컬 저장소(Local Repository)로 복제하는 것

Git 업로드

기초 명령어

  1. 초기 작업: 로컬 저장소 생성 및 원격 저장소와 연결
    • git init: Local 환경에 Repository 생성(Remote 환경의 Repository는 GitHub에서 생성)
    • git remote add origin <url>: 로컬 저장소와 원격 저장소(origin)를 연결
  2. git 저장: push할 파일 commit 및 메시지 작성
    • git add <file>: push할 특정 파일을 commit 대상에 추가
    • git commit -m "<message>": commit 시 메시지 작성
    • git push -u origin <branch>: 원격 저장소(origin)의 특정 branch에 업로드
  3. 기타
    • git branch: 현재 branch 확인
    • git branch -M <new_branch>: 기존 branch를 새로운 branch로 변경 (예. git branch -M main)
    • git status: 현재 git 상태 확인(commit 한 파일 확인)
