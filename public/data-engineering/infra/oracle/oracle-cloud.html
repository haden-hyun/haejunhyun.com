Oracle 클라우드 생성

Oracle 클라우드 생성

Oct 24, 20262 min read

  • data-engineering/infra
  • docker

Summary

  • 오라클 클라우드는 인스턴스로 가상환경을 생성하고, SSH 키 쌍(public/private)으로 접속하며, public IP를 고정 IP로 변경하는 흐름으로 구성된다.
  • 인스턴스 OS는 반드시 Linux가 아닌 Canonical Ubuntu로 설치해야 한다.
  • 인스턴스 접속 후 Python·Docker·Docker Compose를 설치하여 개발 환경을 구성한다.

개요

인스턴스로 가상환경을 생성하고, 해당 가상환경에 접속하기 위한 SSH 키 쌍(public/private)을 발급한다. private 키는 로컬에서 public IP에 접근하기 위해 사용하며, public IP는 고정 IP로 변경한다.
