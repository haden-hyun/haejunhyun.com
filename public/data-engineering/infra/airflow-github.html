Airflow 환경 GitHub 연동

Airflow 환경 GitHub 연동

Jul 02, 20263 min read

  • data-engineering/infra

Summary

  • Oracle Cloud 서버 내 Airflow 프로젝트를 GitHub와 연동하려면, 서버용 SSH Key를 생성해 GitHub에 등록해야 한다.
  • SSH Key는 RSA보다 생성·검증 속도가 빠른 ed25519 방식을 사용한다.
  • Git 초기화 후 .gitignore로 보안 파일을 제외하고, 원격 저장소에 연결해 업로드한다.

들어가며

Oracle Cloud를 통해 서버를 생성하고, Airflow 및 PostgreSQL까지 구축하였다. 이제 서버 내 Airflow 프로젝트를 GitHub와 연동하여 관리해본다. 서버가 GitHub에 접속할 수 있도록 서버용 SSH Key를 생성해서 GitHub에 등록하는 작업이 필요하다.

SSH Key

생성 및 복사

ssh-keygen을 통해 key를 생성한 후, Enter 키를 3번 누른다.

ed25519란?

  • 현재 가장 추천되는 최신 암호화 방식이다.
  • 과거 RSA 방식은 길이가 너무 길고 리소스를 많이 잡아먹는다.
  • 이를 개선한 ed25519는 키 생성과 검증 속도가 훨씬 빠르다.

GitHub 등록

  1. GitHub → Settings → SSH and GPG keys
  2. New SSH key 클릭
  3. Title: Oracle Cloud Server
  4. Key: 복사한 내용 붙여넣기 → 저장
