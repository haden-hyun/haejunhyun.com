Python Operator 기본

Created 2024-08-23Revised 2026-07-021 min read 

Summary

  • PythonOperator는 사용자가 만든 함수를 실행시켜주는 오퍼레이터다.
  • BranchPythonOperator는 Python 실행 결과에 따라 task를 선택적으로 실행한다.

PythonOperator

PythonOperator는 DAG 내 사용자가 정의한 함수를 실행시킬 수 있게 한다. python_callable에 실행할 함수명을 작성하는 것이 핵심이다.

BranchPythonOperator

BranchPythonOperator는 task1 결과에 따라 task2를 실행시킬지, task3를 실행시킬지 선택한다.
