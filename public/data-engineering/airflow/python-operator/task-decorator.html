Task 데코레이터

Jul 02, 20262 min read

  • data-engineering/airflow

Summary

  • Task 데코레이터는 Python 데코레이터의 기능을 airflow task로 활용한다.
  • Airflow 공식 문서에서도 PythonOperator보다 task decorator 활용을 권장한다.
  • from airflow.decorators import task를 통해 사용한다.

Python 데코레이터

Python 데코레이터란 원래의 함수를 감싸(wrapping) 바깥에 추가 기능을 덧붙이는 것이다. 함수를 직접 수정하지 않고 wrapping 함수로 변경을 최소화할 수 있다.
