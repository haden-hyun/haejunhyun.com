Python Operator 파라미터

Python Operator 파라미터

Jul 26, 20262 min read

  • airflow/operator

Summary

  • 부가적인 변수들을 함수에 사용하기 위해 args, kwargs를 활용한다.
  • args 객체는 tuple 형태, kwargs 객체는 dictionary 형태다.
  • 객체 부여 순서는 필수 파라미터 → args(key-value 형태 전까지) → kwargs(나머지 key-value) 순이다.

*args 변수

  • args 객체는 Tuple 형태다.
  • 부가정보가 없는 경우 인덱싱 오류가 발생하므로 if 조건문으로 안전 로직을 추가한다.

**kwargs

  • kwargs 객체는 Dictionary 형태다.
  • get 함수를 활용하면 key가 없는 경우 에러 대신 None이 반환된다.

args와 kwargs 함께 사용

작동 순서

  1. 필수 파라미터는 각 변수에 캡쳐된다.
  2. key=value 형태가 나오기 전까지 args에 캡쳐된다.
  3. key=value 형태는 kwargs에 캡쳐된다.
