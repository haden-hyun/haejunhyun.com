외부 함수 사용하기

Jul 02, 20262 min read

  • data-engineering/airflow

Summary

  • Airflow는 자동으로 dags 폴더와 plugins 폴더를 sys.path에 추가한다.
  • VSCode(개발환경)와 Airflow(가상환경)는 plugins 경로 인식 방식이 달라 import 오류가 발생할 수 있다.
  • local과 airflow 경로 불일치 오류는 .env 파일에 PYTHONPATH를 추가해 해결한다.
