Airflow 개념 및 작동 원리

Airflow 개념 및 작동 원리

Jul 02, 20263 min read

  • data-engineering/airflow
  • docker

Summary

  • 도커는 앱을 독립적 환경에서 실행시키는 컨테이너화 플랫폼으로, Airflow 설치 방법 중 하나다.
  • 이미지는 컨테이너를 실행하기 위한 템플릿이며, docker-compose는 여러 컨테이너 설정을 한 번에 관리하는 확장 기술이다.
  • Airflow의 작동 원리는 로컬 환경에서 만든 DAG를 가상 서버의 컨테이너까지 배포하는 것이다.

기본 개념

Docker

도커는 컨테이너화 플랫폼으로, App을 독립적 환경에서 실행시킬 수 있는 기술이다. 경량화된 가상화 서버를 의미하며 Airflow 설치 방법 중 하나다. 각각의 App을 **컨테이너(Container)**라고 한다.

컨테이너 가상화

컨테이너 가상화는 Host OS 커널을 사용하여 독립적인 여러 개의 컨테이너를 실행하는 방식이다. 기존 가상화에 비해 더 가볍고 효율적이다.

Image

이미지는 컨테이너를 실행하기 위한 템플릿(Template)이다. 객체 지향 프로그래밍 내 Class와 같이, 이미지는 컨테이너 프로세스 실행 환경을 결정한다.

docker-compose

docker-compose는 도커 내 여러 개의 컨테이너 설정을 한 번에 관리하기 위한 도커 확장 기술이다.

작동 원리

목표

로컬 환경에서 만든 DAG를 가상 서버의 컨테이너(Container)까지 배포한다.

필수 라이브러리

  • airflow.models.dag: DAG 작성을 위함
  • datetime, pendulum: Airflow 시간 설정을 위함

DAG 작성 예시

파라미터 설명

파라미터설명
dag_idAirflow UI 내 DAG 이름 (Python 파일명과 일치 권장)
schedule실행 주기 (분, 시, 일, 월, 요일 순)
start_dateDAG 시작 시간 (tz="Asia/Seoul" 권장)
catchup누락 구간 작업 실행 여부 (일반적으로 False)
dagrun_timeoutDAG 실행 제한 시간
tagsAirflow UI 내 태그 이름
paramsTask 공통 변수 목록
