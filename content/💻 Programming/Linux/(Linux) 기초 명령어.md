## 기초 명령어

| 명령어     | 기능                     | 명령어   | 기능               |
| ------- | ---------------------- | ----- | ---------------- |
| `pwd`   | 현재 디렉토리 경로 출력          | `ls`  | 현재 디렉토리 파일 목록 출력 |
| `cd`    | 디렉토리 변경                | `cp`  | 파일 복사            |
| `mkdir` | 디렉토리 생성                | `mv`  | 파일 이동/이름 변경      |
| `touch` | 새로운 파일 생성              | `tar` | 파일/디렉토리 압축 해제    |
| `rm`    | 파일 삭제(디렉토리 포함: 옵션 `r`) |       |                  |
