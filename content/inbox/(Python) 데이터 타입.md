## 1. 데이터의 종류 (기초 통계 개념)

데이터 분석의 첫걸음은 변수의 성격을 파악하는 것입니다. 크게 수치형과 범주형으로 나뉩니다.

### 📈 수치형 (Numerical)

양적 변수. 숫자로 연산이 가능한 데이터입니다.

- 이산형 (Discrete)    
    - 특징: 딱 떨어지는 정수 값. 셀 수 있음 (Countable).        
    - 예시: 카톡 단어 수, 사고 건수, 사람 수. (3.5명이란 존재하지 않음)
        
- 연속형 (Continuous)    
    - 특징: 연속된 구간의 값. 실수 형태. 측정 가능함 (Measurable).        
    - 예시: 시간, 키, 몸무게. (소수점 무한대까지 표현 가능)
        

### 🗂 범주형 (Categorical)

질적 변수. 그룹이나 분류를 나타내는 데이터입니다.

- 명목형 (Nominal)    
    - 특징: 순서나 서열이 없음. 단순 분류 목적.        
    - 예시: 사용자 이름(`user_name`), 성별, 혈액형.
        
- 순서형 (Ordinal)
	- 특징: 데이터 간에 순서(Rank)**나 등급이 존재함.        
    - 예시: 월(1월→12월), 학점(A→F), 만족도(상/중/하).

## 2. Pandas 라이브러리의 데이터 타입 (dtype)

Python Pandas에서 사용하는 실제 데이터 타입과 실전 활용 팁입니다.

|Pandas dtype|Python type|설명|카카오톡 데이터 예시|
|---|---|---|---|
|int64|int|정수 (Integer)|메시지 길이, 단어 수|
|float64|float|실수 (Floating point)|(평균 답변 시간 등)|
|object|str / mixed|문자열 또는 복합 데이터|메시지 본문(`text`)|
|bool|bool|참/거짓 (True/False)|-|
|datetime64|-|날짜와 시간|전송 시간(`date_time`)|
|category|-|범주형 (유한한 값)|요일, 사용자명|

### 💡 실전 핵심 Tip

- Category vs Object (메모리 최적화)    
    - `object`는 문자열을 그대로 저장하지만, `category`는 내부적으로 숫자로 매핑하여 저장합니다.        
    - Tip: 반복되는 문자열(예: 성별, 지역)이 많다면 반드시 `category`로 변환하세요. 메모리 사용량이 획기적으로 줄고 조회 속도가 빨라집니다.
        
- Int64 vs int64 (결측치 처리)    
    - 기본 `int`(numpy int64)는 `NaN`(결측치)을 가질 수 없어, 데이터에 비어있는 값이 하나라도 있으면 강제로 `float`로 변환됩니다.        
    - Tip: Pandas 최신 버전의 `Int64` (대문자 I) 타입을 사용하면 정수형을 유지하면서도 결측치를 표현할 수 있습니다.

## 3. 데이터 타입 확인 및 변경

### 데이터 타입 확인

```python
df.dtypes       # 각 컬럼의 데이터 타입만 확인
df.info()       # 타입 + 결측치(Non-Null) + 메모리 사용량까지 한 번에 확인 (★추천)
```

### 데이터 타입 변경 방법

1) astype : 데이터가 깨끗할 때

가장 기본적인 변경 방법입니다. 딕셔너리를 활용해 여러 컬럼을 한 번에 바꾸는 것을 권장합니다.


```python
# 컬럼 A는 정수, 컬럼 B는 카테고리로 변경
df = df.astype({
    'msg_len': 'int',
    'user_name': 'category',
    'year': 'category' 
})
```

2) pd.to_numeric / pd.to_datetime : 데이터가 지저분할 때 (★필수)

astype은 '1,000'(콤마 포함)이나 '2023-01-01'(문자열 날짜) 같은 형식을 바로 변환하지 못하고 에러를 냅니다. 이때 전용 함수를 사용해야 합니다.

- 날짜 변환: `pd.to_datetime(df['date'])`    
    - 문자열을 날짜 객체로 똑똑하게 파싱하여 시계열 분석을 가능하게 합니다.        
- 숫자 변환: `pd.to_numeric(df['col'], errors='coerce')`    
    - 변환 불가능한 값(예: '없음', '-')은 `NaN`(결측치)으로 처리하여 에러 없이 강제 변환합니다.
