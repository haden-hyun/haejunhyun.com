## 신경망 임베딩 (Neural Network Embeddings)

임베딩이란? 이산형 변수를 연속 벡터로 나타내는 방법 중 하나
즉, 인코딩 방법과 대조적으로 신경망 임베딩은 저차원이며, 학습이 필요
이를 통해 임베딩 공간에서 서로 유사한 실체를 가깝게 배치

필요사항
- 신경망 모델
- 지도학습
