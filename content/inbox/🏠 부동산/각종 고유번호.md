# 법정동코드

> [!tip] 시군구코드와 법정동코드
> 1. 시군구코드(5) 구성
> 	1. 시도(2) + 시군구(3)
> 2. 법정동코드(5) 구성
> 	1. 읍면동(3) + 리(2)

# PNU(필지고유번호)
>[!hint] PNU(필지고유번호)
>- 지번주소 식별용 KEY
>- 총 19자리
>	- 시군구코드(5) + 법정동코드(5) + 필지구분코드(1) + 본번(4) + 부번(4)
>	- 필지구분코드(1): 일반과 산을 구분하는 코드
>		- 일반적으로 토지, 지적도, 개별공시지가 코드 활용
>		- 토지, 지적도, 개별공시지가: 1-일반 , 2 - 산
>		- 건축물대장: 0 - 일반 , 1 - 산
- 예) 서울특별시 종로구 청운동 1-20번지의 PNU 1111010100100010020
	- 법정동코드(10) > 서울특별시 종로구 청운동 : 1111010100
	- 필지구분(1) > 일반: 1
	- 본번(4) > 1-20번지 중 1 : 0001
	- 부번(4) > 1-20번지 중 20: 0020

# 도로명주소관리번호
> [!hint] 도로명주소관리번호
> 1. 현재_도로명주소관리번호(**26자리**)
> 	1. 시군구코드(5) + **법정동코드**(3) + 도로명번호(7) + 지하여부(1) + 건물본번(5) + 건물부번(5)
> 2. 구버전_도로명주소관리번호(**23자리**) - **법정동 제거**
> 	1. 시군구코드(5) + 도로명번호(7) + 지하여부(1) + 건물본번(5) + 건물부번(5)
> 3. 비공식(빅밸류 버전, **22자리**) - **지하여부 제거**
> 	1. 시군구코드(5) + 도로명번호(7) + 건물본번(5) + 건물부번(5)

# 건물관리번호
> [!hint] 건물관리번호
> - 건물 데이터 식별하기 위한 PK
> 	- **최소 생성 이후 해당 건물의 주소정보가 변경되어도 건물관리번호 코드는 변경되지 않음!!**
> 	- 즉, 지번주소 변경으로 인해 PNU가 변하여도 **건물관리번호는 불변!!**
> - 따라서, 타 데이터와 매칭하는 용도로는 부적합
> - 총 25자리
> 	- PNU 코드(19) + 시스템번호(6)
