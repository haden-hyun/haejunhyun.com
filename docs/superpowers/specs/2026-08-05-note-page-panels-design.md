# 노트 상세 페이지 3패널 개편 — 설계

2026-08-05 · 브랜치 `redesign/v5-homepage`

기준 노트: `data-science/statistics/distribution-transformation-and-matrix`
(빌드본을 로컬 서버로 띄워 computed style을 실측했다. 이 문서의 수치는 전부 측정값이다.)

## 0. 범위

노트 상세 페이지의 세 패널 — 중앙 본문 / 좌측 탐색 / 우측 보조 — 을 한 번에 정리한다.
버그 4건과 설계 변경 6건이 섞여 있고, 버그를 먼저 잡지 않으면 설계 논의가 무의미한
항목(콜아웃·LaTeX)이 있어 한 스펙으로 묶는다.

홈(`index`)은 이번 범위 밖이다. 다만 `quartz.config.yaml`·`custom.scss`를 공유하므로
홈에 회귀가 없는지는 검증 대상에 포함한다.

## 1. 확정된 버그 (실측 근거 포함)

### 1.1 콜아웃 — 3면이 팔레트 밖 색

| 타입 | 좌측 보더 | 나머지 3면 |
|---|---|---|
| note / abstract | `#6fb2e0` (우리 `--secondary`) | `rgba(68,138,255,.267)` = `#448aff44` |
| warning | `#d9a441` (우리 `--cal-warn`) | `rgba(219,137,66,.267)` = `#db894244` |
| quote | `#9a938c` (우리 `--cal-quote`) | `var(--lightgray)` |

`custom.scss` §4는 그룹별로 `--color`만 재정의하고 `--border`는 두었다. base
`callouts.scss`의 `.callout { border: 1px solid var(--border) }`가 살아 있어
좌측 3px만 우리 색이고 나머지는 플러그인 하드코딩 색이 나온다. 타입마다 그 값이
달라 규칙성도 없다.

CLAUDE.md 절대원칙 #2("플러그인이 자기 색 값을 병렬로 정의하면 사이트가 분열된다")가
콜아웃에서 깨져 있는 상태다.

부수: `custom.scss`가 `background:` 숏핸드로 덮으므로 base의 `--bg` 12줄은 죽은 코드다.

### 1.2 LaTeX — 우리 규칙이 적용되지 않음

실측: 인라인·디스플레이 수식 모두 `font-size: 19.36px`, 본문 16px → 정확히 1.21배.

원인이 두 겹이다.

1. `custom.scss`의 `.katex { font-size: 1.05em }`은 **죽은 코드**다.
   `latex` 플러그인이 `externalResources()`로 주입하는 KaTeX CDN CSS가
   `index.css`보다 뒤에 링크되고, KaTeX의 `.katex{font-size:1.21em}`와
   명시도가 같아(0,1,0) 소스 순서로 CDN이 이긴다.
2. KaTeX의 1.21은 KaTeX_Main(Computer Modern 계열, x-height/em ≈ 0.43)이
   **세리프 본문** 옆에서 작아 보이는 것을 보정하는 값이다. 우리 본문은
   Noto Sans KR(x-height/em ≈ 0.53)이라 보정이 필요 없는 자리에 보정이 들어가
   이중으로 커졌다.

즉 "수식이 크다"는 크기 설정 실수가 아니라 이중 보정이다.

부가 실측: 인라인 수식 `line-height` 23.2px vs 본문 30.4px. 큰 글자 + 좁은 행간이라
줄에서 튀어나온다.

### 1.3 Explorer `useSavedState` 옵션이 no-op

`quartz.config.yaml`에 `useSavedState: false`가 있고 HTML에도
`data-savestate="false"`가 실려 나가지만, **`explorer.inline.ts`가 그 속성을 한 번도
읽지 않는다.**

- `Explorer.tsx:80` — `data-savestate` 출력
- `explorer.inline.ts:247` — `localStorage.getItem("fileTree")` 무조건 읽음
- `explorer.inline.ts:338`, `:383` — 무조건 씀

`dataset` 접근은 `dataFns` / `behavior` / `folderpath` 셋뿐이다. 한 번 연 폴더는
localStorage에 영구 누적되고, 페이지를 새로 열 때마다 다시 펼쳐진다.
`quartz.config.yaml`의 해당 주석은 사실과 다르므로 수정 대상이다.

`.quartz/`는 `npx quartz plugin install`이 만드는 생성 디렉터리라 패치가 유지되지
않는다 → 업스트림 수정을 기다리지 않는 구조적 해법이 필요하다(§2.2).

### 1.4 TOC 대비 — AA 위반

base `component-788c9ca3.css`가 `ul.toc-content.overflow > li > a { opacity: .35 }`를
건다. `custom.scss` §8은 `color`만 덮었고 `opacity`는 두었다.

실측 비활성 링크: `opacity 0.35`, 크림 배경 위 **실효 대비 약 1.6:1**.
CLAUDE.md 절대원칙 #1(AA 4.5 예외 없음) 위반이다.

## 2. 설계

### 2.1 색의 세 축 — 확장 범위 확정

기존 축은 유지하고 Chitlins만 한 자리 넓힌다.

| 축 | 색 | 쓰이는 곳 |
|---|---|---|
| 공간 — 갈 수 있는 곳 | 블루 `#1c5f95` | 본문 링크, 백링크, breadcrumb |
| 행위 — 누르는 것 | 브릭 `#b8442a` | CTA 전용 (변동 없음) |
| 시간 — 지금 여기 | Chitlins `#b03a7d` | 읽기 진행바 + **TOC 활성 마커**(신규) |

TOC의 in-view 마커는 "지금 내가 읽고 있는 위치"라 읽기 진행바와 같은 질문에 답한다.
같은 신호가 상단 바와 우측 패널에서 일관되게 나온다.

**하이라이트는 세 축 어디에도 넣지 않는다.** 하이라이트는 명명도 가치도 아닌
"여기 주목"이라, 네 번째 색을 만들면 축 체계가 무너진다. 인라인 코드가 색 대신
무채색 재질로 빠진 것과 같은 해법을 쓴다(§2.4).

### 2.2 좌측 패널 — Explorer 폐기, CATALOG 신설

전체 트리(폴더 32 · 파일 링크 89, 전부 DOM 렌더)를 버리고 현재 노트의 직속
컨텍스트만 보여준다.

```
CATALOG
data-science / statistics          ← 폴더 페이지 링크
   1. 통계학 기초 개념
   2. 기초 통계량과 스케일링
 ▸ 3. 분포 변환과 행렬             ← 현재
   상호정보량(MI)
 ──────────────
 ← 모든 토픽 보기                  ← /topics
```

근거 셋:

1. 길이가 **형제 노트 수**에만 비례한다. 노트가 몇 배가 돼도 한 화면이다.
2. 펼침 상태가 **존재하지 않으므로** §1.3 버그가 우회 대상이 아니라 무관해진다.
3. 은유 정합 — 상단 GlobalNav = 레이블 카탈로그 / 좌측 = 지금 이 판의 트랙 리스트 /
   우측 = 이 트랙 안의 구조. 3층이 갈린다. 지금은 좌측 트리와 `/topics`가 겹친다.

라벨은 **CATALOG**. "Explorer"는 IDE 용어라 은유 밖이고, 8자라 접힘 폭에서도
잘리지 않는다.

트리에 파일처럼 섞여 있던 `Archive` / `Topics` 가상 페이지는 이 전환으로 자연 소멸한다.

구현: `github:quartz-community/explorer`를 `enabled: false`로 두고 로컬 플러그인
`plugins/note-catalog`를 신설한다(기존 17종과 동일한 tsup 패키지 패턴).

⚠️ 형제 목록은 `allFiles` 런타임 집계이며 하드코딩하지 않는다. `frontmatter.title`
유무로 실제 노트를 거를 수 없으므로 `recent-notes-index`의 `isAutoGeneratedPage()`와
같은 **슬러그 패턴 필터**를 쓴다(`tags/` 접두, `index`, `/index` 접미, `404`,
`topics`, `archive`).

정렬은 파일명 자연 정렬(`localeCompare`, `numeric: true`)로 한다. `prev-next`가 쓰는
날짜 정렬과 다른데, 좌측 패널은 "이 폴더의 목차"라 `1. / 2. / 3.` 번호 순서가
사용자 의도이기 때문이다.

### 2.3 우측 패널 — 높이 배분 고정 + 순서 변경

실측: 사이드바 861px 안에서 TOC 가변 → Graph 287px → **Backlinks 52px**(한 줄).

원인: 세 패널이 모두 `flex: 0 1 auto`라 TOC가 자연 높이를 다 먹는다.
`.backlinks > ul.overflow { max-height: calc(100% - 2rem) }`의 `100%`는 부모 높이가
auto라 해석 불가로 무시된다.

| 패널 | 순서 | flex | 비고 |
|---|---|---|---|
| TOC | 1 | `1 1 0` + `min-height: 0` | 남는 공간 전부, 내부 스크롤 |
| Backlinks | 2 | `0 0 auto`, `max-height: 9rem` | 내부 스크롤 |
| Graph | 3 | `0 0 auto`, **기본 접힘** | 클릭 시 확장 |

순서는 `quartz.config.yaml`의 layout priority로 바꾼다(graph 30→50, backlinks 50→30).

⚠️ 각 패널에 `min-height: 0`이 없으면 flex 자식이 실제로 줄지 않는다
(flex 기본 `min-height: auto` 함정).

⚠️ TOC를 감싼 `.desktop-only`는 base.scss:141에서 `display: contents`다. flex에
투명하므로 `.toc` / `.backlinks` / `.graph`를 **직접** 타겟해야 한다.

Graph 기본 접힘: 이 노트의 그래프 노드는 사실상 1개인데 250px를 점유한다. graph
플러그인에는 접기 옵션도 토글 마크업도 없으므로(`Graph.tsx`는 `<h3>` + `.graph-outer`
뿐) `note-catalog` 패키지가 `SidebarGraphFold` 컴포넌트를 함께 내보내 인라인
스크립트로 헤더를 토글 버튼으로 만든다. 렌더 결과물은 없고 스크립트만 싣는다.

### 2.4 중앙 본문

**Breadcrumb** — `custom.scss`에 규칙이 하나도 없고 마지막 크럼까지 `<a href>`라
현재 페이지가 링크처럼 파랗다. "이 판이 어느 시리즈 몇 번인가"라는 좌표이므로
음반 카탈로그 번호처럼 조판한다: JetBrains Mono / 0.7rem / `letter-spacing: .08em`,
조상 `--text-3`, 현재 페이지는 링크 해제 + `--text-2`, 구분자는 더 옅게.
로고(Anton) → breadcrumb(Mono) → 제목(Noto)으로 세 층의 목소리가 갈린다.

**bold** — 실측 `strong`과 `h1~h3`이 둘 다 `--dark`로 완전히 같다. "강조"와 "구조"가
같은 신호를 쓰면 굵은 본문 조각이 소제목처럼 읽힌다. `strong`에서 색을 빼고 무게만
남긴다(본문색 상속). 명도 = 구조(헤딩 독점), 무게 = 강조로 채널이 갈린다.

**italic** — Noto Sans KR에 진짜 이탤릭이 없어 브라우저가 합성 오블리크를 만든다.
한글에서 특히 조악하고 한글엔 이탤릭 관습 자체가 없다. 기울임을 버리고
`--text-3` + 미세 자간으로 "방백/부연"을 표현한다. §11의 캡션 처리와 일관된다.

**하이라이트** — 현재 `#fde68a88`(형광 노랑) / 다크 실효 `rgba(179,170,2,.53)`(올리브)로
팔레트 어디에도 근거가 없다. 웜 뉴트럴 **밑줄 밴드**로 바꾼다
(`box-shadow: inset 0 -0.45em 0`). 채움이 아니라 밑줄인 이유는 인라인 코드 칩
(`#eae4d6` 채움 + 보더)과 값이 가까워 혼동될 수 있어서다 — 칩 = 박스,
하이라이트 = 밑줄로 형태가 갈린다.

값과 검증(밴드 위 본문 대비):

| | 밴드 | 본문 | 대비 |
|---|---|---|---|
| light | `#e5dcc4` | `#323e4c` | 7.99:1 AAA |
| dark | `#2a3444` | `#bcc9d9` | 7.40:1 AAA |

밴드 자체는 순수 장식이라 대비 요구가 없다(배경 대비 light 1.26 / dark 1.47로 식별 가능).

**LaTeX** — CDN 순서를 바꿀 수 없으므로(§1.2) 명시도로 이긴다. `.katex`(0,1,0)를
`body .katex`(0,1,1)로 올리면 소스 순서와 무관하게 우리 값이 적용된다.

- 인라인 `1em` — 임의값이 아니라 `1.21 × (0.43/0.53) ≈ 1.0`, 본문과 x-height가 일치하는 값
- 디스플레이 `1.15em` — 독립 블록이라 커도 되고 오히려 낫다
- `line-height: inherit` — 인라인 수식이 줄에서 튀어나오는 것 교정

### 2.5 유지

**Backlinks 색** — 블루 유지. 백링크는 "여기로 올 수 있는 다른 판"이라 공간 축이 맞다.
base의 `a { color: var(--secondary) }`를 그대로 받으면 된다(custom의 `article a`는
본문 전용이라 간섭하지 않는다).

## 4. 검증

1. `npx quartz build` 성공
2. 콜아웃 4면 보더가 전부 `--color` 파생인지 computed style로 재확인 (note/warning/quote)
3. 인라인 `.katex` computed `font-size` == 본문 `font-size`
4. TOC 비활성 링크 `opacity: 1`, 대비 4.5 이상
5. 우측 패널 3분할이 실제로 배분되는지 (Backlinks 52px → 9rem 확보)
6. 좌측 CATALOG가 형제 노트만, 자동 생성 페이지 없이 렌더되는지
7. 홈(`index`) 회귀 없음 — 좌우 컬럼 숨김, 히어로/Featured/TopicGrid/Recent 정상
8. 라이트/다크 양쪽 확인
