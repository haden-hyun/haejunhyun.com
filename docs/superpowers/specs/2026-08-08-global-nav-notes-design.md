# GlobalNav — 항목 순서 변경 + Notes의 컨텍스트 의존 동작

- 날짜: 2026-08-08
- 대상: `plugins/global-nav`
- 상태: 설계 승인됨

## 배경

현재 상단 내비는 `Home | Notes | Topics | Archive`이고, Notes는 전용 페이지가 없어
`slug: null`로 특수 취급된다. active 판정은 "Home/Topics/Archive 중 무엇도 아니면
Notes"라는 부정 조건이고, 링크는 `/archive`로 보낸다.

이 부정 판정은 태그 페이지·폴더 인덱스·404까지 Notes로 뭉뚱그린다. 그 페이지들은
노트가 아니므로 표시가 사실과 다르다.

## 목표

1. 순서를 `Home | Topics | Archive | Notes`로 바꾼다.
2. Notes에 실제 목적지를 준다 — 노트 위에 있으면 아무 동작도 하지 않고,
   그 밖에서는 가장 최근 노트로 보낸다.

## 동작 규칙

| 현재 페이지 | Notes 렌더 |
|---|---|
| 실제 노트 | `<span class="global-nav-link active" aria-current="page">Notes</span>` — 링크 아님 |
| 그 외 전부 (홈 · `/topics` · `/archive` · 태그 · 폴더 인덱스) | 최신 노트로 가는 `<a>`, active 아님 |

`/404`는 이 표에 없다 — 별도 레이아웃이라 GlobalNav 자체가 렌더되지 않는다(기존 동작).

"실제 노트" = `isAutoGeneratedPage(slug)`가 false이고 `frontmatter.title`이 있는 슬러그.

노트 페이지에서 링크가 아니라 `<span>`인 이유: 자기 자신을 가리키는 href는 스크롤을
맨 위로 튀게 하고 히스토리에 항목을 쌓는다. "아무 기능 없음"이 요구사항이므로
링크 자체를 없앤다.

## 구조

`NAV_ITEMS`가 `slug: string | null` 하나로 두 종류를 태우고 있다. Notes가 동적
타깃을 갖게 되므로 종류를 명시한다.

```ts
const NAV_ITEMS = [
  { label: "Home",    kind: "static", slug: "index" },
  { label: "Topics",  kind: "static", slug: "topics" },
  { label: "Archive", kind: "static", slug: "archive" },
  { label: "Notes",   kind: "latest-note" },
]
```

`NAMED_SLUGS` 기반 부정 판정은 삭제한다. active는 항목별로 스스로 판정한다.

- `kind: "static"` → `currentSlug === item.slug`
- `kind: "latest-note"` → `isRealNote(currentSlug)`

결과적으로 태그·폴더 인덱스 페이지에서는 **네 항목 모두 비활성**이 된다. 그 페이지들이
네 목적지 중 어디에도 속하지 않는다는 사실을 그대로 표시하는 것이다.

## 최신 노트 선정

`allFiles`(`QuartzComponentProps`에 포함)를 다음으로 거른 뒤 정렬한다.

1. 필터: `frontmatter.title`이 있고 `!isAutoGeneratedPage(slug)`
2. 정렬: `dates.modified ?? dates.created ?? 0` 내림차순
3. 첫 항목의 슬러그

정렬 키는 `recent-notes-index`의 `getSortTime`과 동일한 폴백 체인이다. 그래야
Notes가 보내는 노트와 홈 Recent Notes 맨 윗줄이 항상 같은 노트가 된다.

`isAutoGeneratedPage`는 `recent-notes-index`에서 복사한다. 플러그인이 각각 독립
npm 패키지라 공유 유틸이 없고, 이 술어는 이미 저장소 내 8곳에 같은 방식으로 복제돼
있다(`note-specs`, `note-catalog`, `archive-page`, `featured-notes`, `home-hero`,
`topic-grid`, `topics-page`, `related-notes`). 공유 유틸 추출은 이번 범위 밖이다.

### 엣지 케이스 — 노트 0개

필터 결과가 비면 최신 노트가 없다. 이때 Notes는 `/archive`로 폴백한다. 빈 아카이브가
"노트 없음"을 보여주는 편이 깨진 링크보다 낫다.

## 스타일 — 변경 없음

`globalNav.scss`는 요소가 아니라 `.global-nav-link` 클래스로 스타일을 건다. 따라서
`<span>`이 색·서체·`.active` 밑줄을 그대로 상속한다.

hover를 `a`로 좁힐 필요도 없다. `.global-nav-link:hover`와 `.global-nav-link.active`는
명시도가 같고(0,2,0) `.active`가 뒤에 선언돼 이미 이긴다. span은 항상 `.active`를
달고 있으므로 hover 색이 먹지 않는다. `cursor: pointer`도 설정된 적이 없어 커서도
바뀌지 않는다.

## 검증

1. `cd plugins/global-nav && npm run build` (tsup — dist가 커밋 대상)
2. `npx quartz build`
3. `public/`에서 실측:
   - 홈: Notes가 `<a>`이고 href가 최신 노트, active 없음
   - 개별 노트: Notes가 `<span aria-current="page">`이고 active
   - 태그 페이지: Notes가 `<a>`, 네 항목 모두 active 없음
   - 최신 노트 슬러그가 홈 Recent Notes 첫 행과 일치
4. `cd public && python3 -m http.server 8899` — SPA 이동 후 nav가 갱신되는지 확인
5. `public/` 커밋 (갱신하지 않으면 라이브에 반영되지 않음)

## 범위 밖

- `isAutoGeneratedPage` 공유 유틸 추출
- 전용 `/notes` 페이지 신설
- About 등 항목 추가
