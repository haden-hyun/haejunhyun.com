API

Jul 24, 20265분 읽기1,240 words#network
Summary

API는 프로그램끼리 데이터를 주고받는 방법(=코드로 작성된 규칙)이며, 호출자와 제공자 사이의 계약이다. 계약이 명확할수록 시스템은 느슨하게 결합된다.

API란 무엇인가

API(Application Programming Interface)는 프로그램이 다른 프로그램에게 무엇을 요청할 수 있고, 그 대가로 무엇을 돌려받는지를 명시한 규칙의 집합이다. 사용자는 내부 구현을 알 필요가 없고, 제공자는 계약만 지키면 내부를 자유롭게 바꿀 수 있다.

요청과 응답

HTTP 기반 API에서 요청은 메서드·경로·헤더·본문으로 구성된다. 응답은 상태 코드와 본문으로 돌아온다.

# 요청 예시
import requests

res = requests.get(
    "https://api.example.com/v1/users",
    headers={"Authorization": f"Bearer {token}"},
    params={"limit": 20},
)
print(res.status_code, res.json())

REST와 계약

REST는 자원을 URL로 표현하고 동작을 HTTP 메서드에 위임한다. 이 규약이 지켜질 때 클라이언트는 문서를 거의 읽지 않고도 다음 동작을 예측할 수 있다.
