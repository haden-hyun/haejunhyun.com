## 3. 결정 대기

### 3.1 사이드바 그래프 — 주제 그래프 (핵심)

시안: https://claude.ai/artifact/8p52JqdXvwb3oBiKdpbJTd

요구: Related 목록은 끄고(완료), 기존 그래프를 개선한다. 범위는 **현재 노트의 최상위 주제 전체**. 링크가 없어도 어떤 구조 속의 노트인지 보여야 한다.

구성: 노드 = 주제 + 하위 폴더 + 노트. 간선 = 구조(노트→폴더→주제, 얇은 선) + 실제 링크(실선) + 시리즈 순서(파선). 현재 노트 강조, 같은 폴더 형제·링크 이웃은 라벨 상시, 나머지 hover.

| 안 | 모습 | 사이드바(260×280) 실측 |
|---|---|---|
| A 방사형 트리 | 주제 중심, 폴더 안쪽 링, 노트 바깥 링. 현재 노트 항상 3시 방향 | 라벨 겹침 0~2쌍, 큰 주제(39편)에서 형제 라벨 5개 말줄임 |

## 4. 검토 근거 요약

- 이미지: 첨부 156장 중 실제 투명은 1장. 투명화는 자산 재제작이고, 검정 라벨이 다크에서 1.29:1로 떨어진다. 그림자 카드는 다크에서 안 보이고 본문 위계를 흐린다 → 헤어라인 프레임.
- 노트 목록: 텍스트 중심 항목이라 정사각 그리드는 비권고. 카드는 행 86.6px로 Archive 행(40.9px)의 2.1배 → 기존 목록 문법(Archive·Featured) 재사용.
- 그래프: 노트 98편 중 80%가 링크 0, 노트당 링크 0.24, 토픽 간 링크 0. 태그 간선의 68~85%가 폴더 미러 태그. 업스트림 그래프는 링크·태그로만 간선을 만들어 구조가 안 보인다.
- 시리즈 토글: 시리즈 전용 폴더에서는 불필요하지만, 시리즈와 일반 노트가 섞이면 접힌 묶음이 폴더를 잘게 쪼개지 않게 해 준다(사용자 지적 반영).
- 비교 페이지(라이브 vs 빌드본): https://claude.ai/artifact/4JqjK9aj9xPa9sN91zpAca
